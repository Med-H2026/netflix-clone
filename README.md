# Netflix Clone

A Netflix-inspired streaming web app built with React + Vite, powered by TMDB API.

## Features
- **Home Page:** Navbar, Hero Section, Horizontal Movie Rows by Category, Footer
- **Dynamic Movies:** Fetches real data from TMDB API (Trending, Top Rated, Action, Comedy, etc.)
- **Player Page:** Click any movie card to watch its trailer in an embedded YouTube player using movie ID

## Tech Stack
React, Vite, JavaScript, CSS, React Router, TMDB API
